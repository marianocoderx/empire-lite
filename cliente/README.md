# Empire-lite Documentacion

## 1.Introduccion

El siguiente proyecto, es un juego interactivo donde cuya finalidad, es proporcionar una plataforma lúdica-interactiva para aprender o participar en cuestiones de geopolitica, economía, y desarrollo, de una manera entretenida. 

La pregunta es, en qué consiste? ...

El nombre Empire-lite,está inspirado en el nombre de un legendario juego de estrategia llamado "Age of empires". El mismo permitía al jugador forjar y gestionar una civilizacion, donde en ella implicitamente se tratan aspectos de gestion politica y estrategia. Le agregué el termino 'lite' para hablar de una version parecida, pero es ligera y es un MVP para demostrar en este portfolio.

## Porqué lo hice?

Mi finalidad es poder proporcionar una herramienta que sea didactica, amena y entendible para entender tematicas mencionadas, y ademas es un videojuego que favorezca el ocio.

## Cómo lo implementé?

Lo hice con un stack de herramientas variado. Por un lado en el frontend se usó Vite junto a React y TypeScript, combinado con Tailwind para los estilos. Además se implementó PixiJS para establecer el mapa y las animaciones, junto con Framer option para las transciones de la interfaz. 

Por otro lado, en el backend, se aplicó NestJS y Prisma.
